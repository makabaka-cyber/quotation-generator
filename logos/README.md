# Logo 文件目录

将各保险公司和品牌的 logo 图片放在此目录下。

## 支持的文件名（按关键词自动匹配）

| 文件名 | 匹配关键词 | 对应公司/品牌 |
|--------|-----------|-------------|
| `pingan.png` | 平安 | 中国平安财产保险股份有限公司 |
| `chinalife.png` | 人寿 | 中国人寿财产保险股份有限公司 |
| `cpic.png` | 太平洋 | 中国太平洋财产保险股份有限公司 |
| `picc.png` | 人保 / 人民财产 | 中国人民财产保险股份有限公司 |
| `taiping.png` | 太平 | 太平财产保险有限公司 |
| `chinaunion.png` | 中华联合 / 中华 | 中华联合财产保险股份有限公司 |
| `aito.png` | 问界 | 问界（品牌） |

## 图片要求

- 格式：PNG（支持透明背景）
- 建议尺寸：宽度 200-400px，高度自适应
- 命名：使用上表中的文件名（小写字母）

## 工作原理

系统按以下优先级查找 logo：
1. 本地 `logos/` 目录（按文件名匹配）
2. 环境变量 `INSURANCE_LOGO_URL` / `CAR_BRAND_LOGO_URL`
3. 报价单表中的 logo 字段
4. 图标表兜底查询

## 获取 logo 图片

1. 从飞书图标表下载对应的 logo 附件
2. 或从官网截图/下载品牌 logo
3. 重命名为上表中的文件名
4. 放入 `logos/` 目录
5. 推送到 GitHub 触发 Railway 重新部署
